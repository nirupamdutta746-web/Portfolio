## 🚀 Getting Started

Follow these steps to set up and run the project locally.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v16+) and `npm` installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/nirupamdutta746-web/Portfolio.git](https://github.com/nirupamdutta746-web/Portfolio.git)
   ```
2. Navigate into the project directory:
   ```bash
   cd Portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the local development server:
   ```bash
   npm start
   # or if using Vite: npm run dev
   ```
5. View in browser:
Open http://localhost:3000 (or the local URL printed in your terminal).

## 🧠 Engineering Decisions
- Modular Architecture: Kept components isolated and reusable so new projects and milestones can be added quickly.

- Performance Optimization: Prioritized minimal bundle sizes and optimized asset loading to maintain high performance across varying network speeds.
